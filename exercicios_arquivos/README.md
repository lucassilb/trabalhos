# Exercicios de Arquivos

Esta pasta cobre os desafios e exercicios de manipulacao de arquivos citados no PDF.

## Scripts

- `desafio_meuarquivo.py`: cria `meuarquivo.txt`, escreve tres linhas e le o conteudo.
- `contador_palavras.py`: conta palavras de um arquivo de texto.
- `concatenador_arquivos.py`: concatena dois arquivos de texto em um terceiro.
- `busca_em_arquivo.py`: busca uma palavra em um arquivo e informa as linhas.
- `ordenador_linhas.py`: ordena linhas em ordem alfabetica e salva em outro arquivo.

Todos os scripts rodam com:

```powershell
python nome_do_script.py
```
